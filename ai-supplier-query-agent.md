# AI-Studio Supplier Query Agent

## Objective

Provide a conversational way to retrieve supplier information using a supplier number.

## Configuration

The solution uses:

- A Supplier Business Object
- A supplier lookup function
- A Supplier Lookup Tool
- A Supplier Query Topic
- An AI Studio Supplier Query Agent

The lookup function retrieves supplier details using a supplier number and can return supplier attributes including supplier name, supplier number, spend authorization, tax country, tax organization type, legacy supplier number and data source.

## Result

Users can provide a supplier number and receive the corresponding supplier information in a conversational response.
