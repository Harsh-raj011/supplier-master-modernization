# Supplier Master Data Conversion

## Objective

Convert priority supplier records into Oracle Fusion Cloud while maintaining the information required to trace converted records back to their legacy supplier records.

## Process

1. Prepare supplier master data using the Oracle supplier interface template.
2. Populate required supplier information and traceability attributes.
3. Generate the supplier CSV/ZIP file.
4. Upload the file through Oracle Fusion Files Import and Export.
5. Use the supplier import process to load the data.
6. Verify successful processing.
7. Search for the imported supplier and validate the converted supplier details.

## Traceability

The project uses conversion-source information and the legacy supplier number as traceability attributes.

## Skills Demonstrated

- Supplier master data
- Data conversion
- Data validation
- Legacy-to-cloud traceability
